# Index — 09-glossary-and-links

**How to read this folder.** This is a *living reference*, not a course — you don't read it front to back. Use it three ways:

1. **Look up terms** — hit a word in 00–08 you don't know (TTFT, MoE, KV cache, speculative decoding…)? It gets defined here.
2. **Curated links** — the best external resources per topic, in one place.
3. **Video master list** — every entry from all the `videos.md` files, as a watch queue.

**Status:** work in progress — the glossary and curated links are filled in continuously as new terms and resources show up in the other folders. Currently only `videos.md` exists.
